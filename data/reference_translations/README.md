# data/reference_translations

Working area for reference translations before they are attached to passages
(`Passage.reference_translations`).

Requirements per reference:
- produced by a named human translator (`human_expert` / `human_non_expert`) or taken from a
  rights-cleared published edition (`published_edition` + `source_citation`);
- **independent of every evaluated model**: not machine-generated, not post-edited from machine output;
- `rights_status` recorded, and the text committed only if rights permit;
- multiple legitimate references per language are welcome; record ambiguities rather than forcing
  one reading.

No reference translations have been obtained yet (CAL-09).
