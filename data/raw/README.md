# data/raw

Local storage for facsimile images, PDFs and other downloaded source material. **Everything here
except this README is git-ignored**, because digital facsimiles often carry reuse restrictions.

Record what you downloaded (URL/ARK, date, licence) in the source registry rather than committing
the files. If a file's rights permit redistribution, document that in the registry and add it with
`git add -f`, after review.
